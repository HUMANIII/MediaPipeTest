# Sakura Hair — 월드 아래 방향 흐름

- [6초 재생 영상](SakuraHairWorldDown.mp4): 실제 Unity Play Mode 렌더링. 고정 카메라, 1280×1280, 30fps, H.264.
- [영상 및 비교 화면](index.html), [효과 끄기](front-off.png), [효과 켜기](front-on.png), [측면](side-on.png), [후면](back-on.png).
- [캐릭터를 25도 기울인 상태](tilted-t0.png)와 [0.2초 후](tilted-t0.2s.png).

꽃잎은 월드 좌표의 `(0, -1, 0)` 방향으로 흐릅니다. 첫 번째 층은 초당 0.065m, 뒤의 두 층은 각각 1.27배·1.54배 속도로 이동합니다. 기존 머릿결은 UV0를 유지하며 꽃잎에만 월드 투영을 사용합니다.

## 검증 결과

| 검사 | 결과 |
|---|---|
| Unity 6000.3.23f1 / RTX 3070 Ti Play Mode | 180프레임 캡처, 실행 오류 및 셰이더 메시지 없음 |
| 저장된 씬 재열기와 그래프 재임포트 | 오류 없음, 월드 방향·속도·텍스처 유지 |
| 일반 자세에서 0.2초간 꽃잎 이동 | 렌더 이미지 상관 분석의 최대 일치 이동량: 화면 아래 32px, 왼쪽 2px |
| 캐릭터를 25도 기울인 상태 | 같은 분석에서 화면 아래 32px, 좌우 0px |
| 효과 강도 0·발광 1 / 밀도 0 | 효과 끄기 이미지와 픽셀 일치 |
| 정면·측면·후면 | 꽃잎 윤곽 확인. 사각 텍스처 배경 없음 |
| 변신 제어 / 파티클 | 데모 씬에 없음 |
| 원본 Henshin 씬·프리팹·모델·공유 머티리얼·제공 리소스 | 178개 파일 SHA-256 일치 |

움직임 분석은 효과 끄기 이미지를 빼고 두 실제 렌더 프레임의 밝기 패턴을 비교한 결과입니다. 여러 속도의 층과 좌우 흔들림이 섞이므로 개별 꽃잎의 정확한 물리 궤적 측정은 아닙니다. 기울임은 캡처 중에만 적용했으며 저장된 씬의 자세는 유지됩니다.

`Time.captureFramerate=30`으로 캡처 간격을 고정했습니다. 영상은 실시간 성능 벤치마크가 아니며 Blender는 PNG 프레임의 H.264 인코딩에만 사용했습니다. 곡면에는 투영에 따른 무늬 변형이 있을 수 있습니다. 독립 플레이어 빌드와 장시간 성능 측정은 수행하지 않았습니다.

## 근거

- `runtime-validation.json`: 실제 Play Mode 시간, 프레임, 설정, 셰이더 메시지.
- `saved-scene-validation.json`: 별도 Unity 실행의 재임포트·재열기 결과.
- `world-motion-validation.json`: 일반 자세와 기울인 자세의 이동 분석, 효과 끄기 비교, 원본 보존 확인.
- `media-validation.json`: MP4 컨테이너의 길이, 해상도, 프레임 수, 코덱.
- `Frames/`: Unity가 출력한 원본 프레임 180개.

사용법과 조절 항목은 `Assets/SakuraHairDemo/README.md`를 참조합니다. 상위 폴더의 이전 캡처는 UV 기반 버전의 기록입니다.

개별 PNG 시퀀스인 "Frames/"는 로컬 캡처 산출물로 보존하며 Git 커밋에서는 제외합니다. 비교 이미지, MP4 영상과 검증 JSON은 함께 보관합니다.
