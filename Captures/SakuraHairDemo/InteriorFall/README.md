# Sakura Hair — 내부에서 독립적으로 떨어지는 꽃잎

- [6초 실제 재생 영상](SakuraHairInteriorFall.mp4): Unity 6000.3.23f1 Play Mode, RTX 3070 Ti, 1280×1280, 30fps, H.264.
- [영상 및 비교 화면](index.html), [효과 끄기](front-off.png), [효과 켜기](front-on.png), [측면](side-on.png), [후면](back-on.png).

앞 3초는 고정 카메라로 낙하를 보여주고 뒤 3초는 카메라를 28도 돌려 깊이감을 보여줍니다. 각 꽃잎은 머리 표면과 별도의 3D 위치를 갖고 월드 아래로 이동합니다. 머리카락 윤곽이 보이는 범위를 제한하며, 꽃잎 형태와 음영은 머릿결을 따라 휘지 않습니다.

## 확인 결과

| 검사 | 결과 |
|---|---|
| Unity Play Mode / 셰이더 컴파일 | 오류 및 셰이더 메시지 없음 |
| 일반 자세에서 0.2초간 이동 | 실제 렌더 영상 상관 분석: 화면 아래 30px, 왼쪽 2px |
| 25도 기울인 자세 | 아래 26px, 오른쪽 2px. 월드 아래 방향 유지 |
| 표면 위치 독립성 | 같은 시선을 받는 평면을 0.55m와 0.8m 거리에 배치. 내부 꽃잎의 픽셀 평균 차이 0.067/255 |
| 효과 강도 0·발광 1 / 밀도 0 | 효과를 끈 이미지와 픽셀 일치 |
| 얼굴·의상 표본 영역 | 효과 전후 픽셀 일치 |
| 정면·측면·후면 | 표면 굴곡에 의한 꽃잎 늘어짐과 사각 배경 없이 표시 |
| 저장된 씬 재열기 | 기본값·텍스처·머리 경계 컴포넌트 유지 |
| 원본 씬·프리팹·모델·공유 머티리얼·제공 리소스 | 178개 파일 SHA-256 일치 |

표면 독립성 검사는 `probe-surface-near.png`와 `probe-surface-far.png`를 비교합니다. 머리카락 대신 서로 다른 깊이의 검은 평면을 창으로 사용해 꽃잎의 위치가 표면 위치에 따라 달라지지 않는지 확인했습니다. 미세한 부동소수점 및 래스터 차이는 허용합니다. 낙하 분석 수치는 여러 꽃잎 패턴의 최대 상관 이동량이며 개별 꽃잎의 정확한 물리 궤적 측정은 아닙니다.

## 근거 파일

- `runtime-validation.json`: Play Mode 프레임, 시간, GPU, 오류, 셰이더 메시지, 내부 공간 설정.
- `saved-scene-validation.json`: 별도 Unity 실행에서 재임포트 및 씬 재열기 결과.
- `interior-motion-validation.json`: 낙하·표면 독립성·효과 끄기·원본 보존 검사.
- `media-validation.json`: MP4 해상도·길이·프레임 수·코덱.
- `Frames/`: Unity 렌더 프레임 180개.

`Time.captureFramerate=30`으로 간격을 고정했습니다. Blender는 실제 Unity 프레임의 영상 인코딩에만 사용했습니다. 플레이어 빌드 및 실시간 성능 벤치마크는 수행하지 않았습니다. 이 표현은 머리카락 윤곽 안의 가상 공간이며 별도의 파티클 오브젝트나 실제 투명 머리 모델을 생성하지 않습니다.

개별 PNG 시퀀스인 "Frames/"는 로컬 캡처 산출물로 보존하며 Git 커밋에서는 제외합니다. 비교 이미지, MP4 영상과 검증 JSON은 함께 보관합니다.
