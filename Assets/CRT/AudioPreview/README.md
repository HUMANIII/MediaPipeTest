# CRT Audio Lab

Unity의 `Tools > CRT > Audio Preview`에서 연다. Play 모드에 들어가지 않고 AudioClip을 재생하며 소리를 조절하는 Editor 도구다.
선택한 AudioClip의 소리 데이터를 임시 클립에서 처리한다. 원본 파일이나 AudioListener에는 효과를 적용하지 않는다.
설정 에셋을 다른 클립에 재사용할 수 있다. 현재 [감시실 데모](../Surveillance/README.md)의 CRT 발소리에 `Presets/DefaultCRT.asset`이 연결되어 있으며, 이 에셋에 저장한 음색이 게임에도 적용된다.

## 사용

1. 창은 마지막에 실제로 재생한 클립을 복원한다. 기록이 없거나 파일이 삭제됐으면 빈 상태로 시작하며, 자동 재생하지 않는다. `오디오 클립` 칸에 AudioClip을 끌어 넣거나 `A 발소리 불러오기`를 누른다.
2. `재생`을 누르고 `반복`을 켜면 같은 클립을 계속 들을 수 있다. 일시정지·정지와 파형 클릭 또는 재생 위치 슬라이더로 구간 이동을 지원한다.
3. `원본 듣기`와 `CRT 효과 듣기`로 같은 재생 위치에서 비교한다. 원본 비교 중에도 저장된 효과 설정은 유지된다.
4. 기본 화면의 `음색 강도`로 전체 음색을 조절한다. −100은 약하게, 0은 기본 CRT, +100은 강하게다. **0은 효과 없는 원본을 뜻하지 않는다.**
5. `자세히 조절하기`를 켜면 간편 슬라이더가 비활성화되고 현재 음색에서 개별 요소를 조절할 수 있다. 끄면 마지막 간편 값으로 돌아간다. 다시 켜면 그 시점의 간편 음색을 이어받으므로 상세 편집을 보관하려면 설정 에셋으로 저장한다.
6. `새 설정 에셋 저장…`으로 `.asset`을 만든다. 기존 에셋 수정은 `설정 에셋에 저장`을 누른다. 사용자용 WAV 저장 기능은 제공하지 않는다.

| 조절 | 역할 |
|---|---|
| 음색 강도 | −100~+100. 여러 음색 요소를 함께 조절한다. 기본값은 0이다. |
| 출력 볼륨 | 기존과 같은 −40~+12dB 슬라이더. 간편·상세 및 원본·효과 비교 모두에 적용한다. |
| 효과 혼합 | 상세 화면에서만 표시. 0%는 원본, 100%는 설정한 CRT 음색이며 중간 값은 두 신호의 혼합이다. |
| 저음 제거 | 올릴수록 낮은 음역이 줄고 얇은 스피커 음색이 된다. |
| 고음 제한 | 내릴수록 고음이 줄고 먹먹해진다. |
| 찌그러짐 | 부드러운 포화 왜곡을 섞는 양. |
| 잡음 | 스피커의 작은 히스와 험. 원본 모드와 상세 효과 혼합 0%에서는 제거된다. |
| 피크 보호 | 0.98을 넘는 출력 피크를 부드럽게 제한한다. 기본값은 켬이다. |

`약하게 / 기본 CRT / 강하게` 버튼은 상세 화면에만 나타난다. 음색 버튼이나 모드 전환은 출력 볼륨·피크 보호·원본 비교 상태를 바꾸지 않는다.
설정 변경은 스트리밍 처리에 반영되며 약 30ms 보간과 Unity 오디오 버퍼 지연이 있다. 재생을 처음부터 다시 시작하지 않는다.

| 간편 값 | 효과 혼합 | 저음 제거 | 고음 제한 | 찌그러짐 | 잡음 |
|---|---:|---:|---:|---:|---:|
| −100 | 50% | 150Hz | 6500Hz | 10% | 2.5% |
| 0 | 100% | 250Hz | 3500Hz | 20% | 8.333% |
| +100 | 100% | 450Hz | 2200Hz | 65% | 25% |

기준 사이의 주파수는 로그 보간, 나머지는 선형 보간한다.

## 설정 에셋과 복원

- 설정 에셋에는 실제 효과 설정·출력 볼륨·피크 보호·간편/상세 모드·간편 값만 저장한다. 클립·재생 위치·원본 비교 상태는 저장하지 않는다.
- 원본을 비교 청취 중이어도 구성한 CRT 설정을 저장한다. 클립 없이도 설정 편집과 저장이 가능하다.
- 설정 에셋을 선택하면 저장한 조절 모드와 값을 복원하고 현재 클립에 적용한다. 클립을 바꾸어도 효과 설정은 유지한다.
- 이전 형식의 프리셋은 상세 모드로 읽어 기존 음색을 보존한다. 명시적으로 저장할 때만 새 형식으로 기록한다.
- 마지막 재생 클립은 프로젝트별 EditorPrefs에 GUID로 기록한다. 선택만 한 클립은 기록하지 않는다. 파일 이동·이름 변경 뒤에도 같은 GUID로 복원한다.
- 새 창과 Unity 재시작 후에는 간편 0·출력 0dB·피크 보호 켬으로 시작한다. 같은 Editor 세션의 재컴파일에서는 편집 중인 클립·모드·설정을 유지하되 재생은 정지한다.

기본 음색은 250Hz 하이패스, 3500Hz 로우패스, 20% 포화 혼합, 약 8.3% 잡음이다.
이 도구는 클립마다 원본과 처리 결과의 RMS를 자동 정규화하지 않는다. 앞서 만든 음원 비교 파일은 파일별 음량을 맞췄으므로 기본 설정과 출력 크기가 완전히 같지는 않다.

## 보존과 범위

- AudioClip의 원본 PCM과 임포트 설정을 수정하지 않는다. 압축/Streaming 클립은 로컬 원본 파일을 메모리에서 별도로 디코딩한다.
- 기본 예시만 무손실 PCM/Decompress On Load로 임포트해 A 음원의 데이터를 보존한다.
- WAV, OGG, MP3, AIFF의 로컬 파일 디코딩을 지원한다. 미리듣기는 8~192kHz, 1~8채널, 채널 합산 2천만 샘플 이하로 제한한다.
- 모노·스테레오의 원래 채널 수와 샘플레이트를 유지한다. 설정 에셋은 선택한 클립의 샘플레이트와 무관하게 저장하며, 청취 시에만 지원 음역으로 제한한다.
- UI 설정을 바꾸는 것만으로 프리셋 에셋을 덮어쓰지 않는다. 저장 버튼을 눌러야 기록된다.
- 창 닫기·스크립트 재컴파일 시 임시 클립을 정리한다. Play 모드 진입 시 미리듣기를 정지한다.
- Unity 기본 Inspector 오디오 미리듣기와 출력 채널을 공유한다. 이 도구에서 재생하면 기존 Inspector 미리듣기는 정지한다.
- 조절 창과 미리듣기는 Editor 전용이다. 설정·간편 조절 계산·DSP는 `Runtime/MediaPipeTest.CRT.Audio` 어셈블리로 공유하며, 감시실의 CRT 발소리에도 같은 코드를 사용한다. 이 창 자체는 씬이나 AudioListener를 수정하지 않는다.

감시실은 `Presets/DefaultCRT.asset`을 기본 참조한다. 이 에셋을 선택해 저장하면 실제 CRT 발소리에도 적용된다. 별도 에셋으로 저장했다면 감시실 `CCTV Footstep Speaker`의 `preset`에 지정한다. 자세한 동작은 [감시실 사용 안내](../Surveillance/README.md)를 참고한다.

## 출처

예시 `Examples/A_Recorded_Original.wav`는 사용자가 선택한 실녹음 비교 파일의 사본이다.
Fantozzi의 Stone L1~L3/R1~R3 녹음을 qubodup이 단발음으로 정리한 CC0 자료를 기반으로 한다.
음량 조정, DC/극저역 정리, 끝단 페이드, 발걸음 배열 편집을 적용했다.

- [음원 배포 및 CC0 표기](https://opengameart.org/content/fantozzis-footsteps-grasssand-stone)
- [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- 원본/합성 비교 및 출처 상세: 프로젝트 `AudioPreviews/CRT_Footsteps/README.md`

Unity Editor 미리듣기는 현재 설치된 Unity 6000.3.23f1에서 확인한 내부 AudioUtil API를 사용한다.
[Unity 6000.3 AudioUtil 참조 소스](https://github.com/Unity-Technologies/UnityCsReference/blob/6000.3/Editor/Mono/Audio/Bindings/AudioUtil.bindings.cs).
다른 Unity 버전에서 해당 메서드가 없으면 명시적으로 지원 불가를 알린다.

## 검증

`Tools > CRT > Validate Audio Preview`로 DSP·검사용 PCM 출력·실제 Editor 스트리밍 재생을 검사한다.
`Tools > CRT > Validate Audio Controls`로 간편/상세 전환·설정 에셋·클립 복원을 검사한다.
검사 중 짧게 오디오가 재생된다. 결과와 비교 WAV는 `Logs/CRTAudioPreview`에 남긴다.
최종 결과는 [VALIDATION.md](VALIDATION.md)에 기록한다.
